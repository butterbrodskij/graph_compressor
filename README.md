# Graph compressor

Однопоточный компрессор неориентированных взвешенных графов на C++17.

## Сборка и запуск

```sh
cd graph_compressor
make
./run -s -i input.tsv -o graph.bin
./run -d -i graph.bin -o output.tsv
```

Сборка без Make:

```sh
c++ -O3 -DNDEBUG -std=c++17 -Wall -Wextra -Wpedantic \
    main.cpp bit_io.cpp arithmetic.cpp graph_io.cpp codec.cpp -o run
```

Поддерживаются только параметры `-s`, `-d`, `-i` и `-o`. При успешной работе программа ничего не выводит в stdout и stderr. Ошибки файлового ввода-вывода сообщаются в stderr и приводят к ненулевому коду завершения.

Входной граф считается корректным по условию задания: три целых числа через табуляцию, ID в диапазоне `uint32_t`, вес в диапазоне `uint8_t`, без кратных рёбер. Петли допустимы. Поддерживаются произвольный порядок рёбер и их концов, LF, CRLF и отсутствие перевода строки в конце файла. Декодер получает архив, созданный этой же версией программы. Проверки содержимого TSV и архива отсутствуют.

Выходной TSV отсортирован по паре ID, меньший ID записан первым. Разделители — табуляция и LF; веса остаются связаны со своими рёбрами.

## Алгоритм

1. Канонизировать и отсортировать рёбра. Собрать отсортированный словарь ID и заменить ID плотными номерами `0..N−1`.
2. Словарь хранить как `id[0]`, затем `id[i] − id[i−1] − 1`. Промежутки кодировать кодом Райса, выбрав параметр `0..32`, дающий минимальный размер.
3. Отделить петли и интерполяционно закодировать возрастающий список их вершин. Этот примитив используется только для петель.
4. Структуру остальных рёбер сжать методом **degree**:
   - Записать полные степени без петель кодом Райса.
   - Обходить источники по возрастанию. Число ещё не записанных исходящих рёбер равно оставшейся степени источника, поэтому отдельные длины списков не нужны.
   - Средний элемент отсортированного списка соседей кодировать целочисленным арифметическим кодером с частотами, равными оставшимся степеням допустимых соседей. Затем рекурсивно обработать левую и правую части списка.
   - Суммы частот и поиск по частоте выполнять деревом Фенвика. Источник удалять из модели перед обработкой строки; степени соседей уменьшать после строки.
5. Сохранить веса по одному байту: сначала веса петель в порядке вершин, затем веса непетлевых рёбер в порядке `(source, target)`.

Кодер использует целочисленную арифметику; результат не зависит от порядка входных строк. Арифметическая модель рассчитана на суммарную частоту до `2^30`, что покрывает ограничения задачи.

## Бинарный формат

Формат упрощён и несовместим с прежним `GRCMP001`: старые архивы нужно создать заново из TSV. Многобайтовые числа записаны в little-endian.

Последовательно хранятся:

1. Параметр Райса для словаря — 1 байт.
2. Параметр Райса для степеней — 1 байт.
3. Число вершин — 8 байт.
4. Число петель — 8 байт.
5. Четыре секции: словарь ID, степени, соседи, номера вершин с петлями. Перед каждой секцией записана её длина в байтах как 8-байтовое число.
6. Веса рёбер — все оставшиеся байты файла.

Биты внутри секций записаны от старшего к младшему; последний байт дополнен нулями. Арифметический декодер дополняет конец своего потока нулевыми битами.

## Проверки

```sh
make test           # восстановление 94 графов и детерминированность
make test-example   # те же проверки плюс small_example.tsv
```

Кодер и декодер запускаются отдельными процессами. Тесты независимо сравнивают рёбра и веса, проверяют формат вывода и отсутствие диагностического вывода при корректном запуске. Покрыты пустой граф, петли, все 256 весов, крайние ID, звёзды, цепочка, полные и случайные графы, перестановки строк и концов рёбер.

## Файлы реализации

- `main.cpp`: режимы сериализации и десериализации.
- `graph_io.h` / `graph_io.cpp`: типы графа и архива, TSV, перенумерация вершин и бинарный формат.
- `bit_io.h` / `bit_io.cpp`: битовые потоки и код Райса.
- `arithmetic.h` / `arithmetic.cpp`: арифметический кодер и дерево Фенвика.
- `codec.h` / `codec.cpp`: degree-сжатие, кодирование списка петель и восстановление графа.
- `tests/test_roundtrip.py`: независимые проверки через CLI.

В заголовках находятся определения типов и объявления функций и методов. Реализации вынесены в `.cpp`; вспомогательные функции, включая шаблон кодирования списка петель, скрыты в анонимных пространствах имён соответствующих `.cpp`.
